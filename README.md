# Factory Planner (Net Output Calculator)

本工具用于自动化游戏中的净产出计算。

计算定义：

- 表观产出：物品作为配方产物时的总产出速率（/min）
- 消耗：物品作为其他配方原料时的总消耗速率（/min）
- 净产出：`表观产出 - 消耗`（可为负数）

## 交互方式

页面初始状态：数据列表与结果表均为空。

1. 在“配方”组合框输入关键字或直接下拉选择配方。
2. 可切换搜索范围：匹配原料、匹配产物、同时匹配原料和产物。
3. 搜索框支持键盘操作：`↑/↓` 选择下拉项，`Enter` 选中，`Esc` 收起；点击输入框会全选文本。
4. 点击“添加”加入数据列表。
5. 可在列表中点击“删除”移除某条数据。
6. 点击“计算”得到所有相关物品的表观产出、消耗、净产出。
7. 结果以表格展示，可点击“查看”展开每种物品被哪些配方消耗以及对应速率。
8. 若某物品表观产出、总消耗、净产出三项均为 0，则结果中不显示该物品。

## 配方库维护（开发者）

开发者只需要修改 `recipe_database.js`。

字段约定（snake_case）：

- `recipe_id`: 配方唯一 ID
- `recipe_name`: 配方展示名称
- `inputs`: 输入物品映射，格式 `{ 物品名: 数量 }`
- `outputs`: 输出物品映射，格式 `{ 物品名: 数量 }`

说明：

- 若需要表达外部输入（例如采矿），可添加无输入配方：`inputs: {}`。

## 测试案例（可手动录入）

配方：

- 铁矿输入（无输入 -> 1铁矿）
- 1铁矿 -> 1铁锭
- 1铁锭 -> 2铁板
- 1铁板 + 2铁锭 -> 2铁齿轮
- 2铁板 -> 3铁外壳

当数据列表录入为以下表观产出对应配方速率时：

- 铁矿 10/min
- 铁锭 10/min
- 铁板 10/min
- 铁外壳 3/min
- 铁齿轮 4/min

计算结果应为净产出：

- 铁矿 0/min
- 铁锭 1/min
- 铁板 6/min
- 铁外壳 3/min
- 铁齿轮 4/min
